# Namaz Vaxtı (Android)

Namaz vaxtlarını **yalnız** `https://ixlasla.com/api/prayer-times` ünvanından götürür və hər namaz vaxtı daxil olanda bildiriş göndərir.

## APK-nı almaq (GitHub ilə, kompüter tələb etmir)
1. github.com-da yeni repo yaradın (məs. `namaz-vaxti`).
2. Bu qovluğun bütün fayllarını (`.github` qovluğu daxil) repoya yükləyin.
3. Repoda **Actions** bölməsinə keçin, "APK yığ" işinin bitməsini gözləyin (~3–5 dəq).
4. İşin səhifəsinin aşağısında **Artifacts → NamazVaxti-apk** yükləyin, zip-i açın: `app-debug.apk`.

## Android Studio ilə
Qovluğu Android Studio-da açın → Build → Build APK(s).

## Telefona quraşdırmaq (Samsung S23 Ultra)
- APK-nı açın → "Naməlum mənbələrdən quraşdırmaya" icazə verin → Quraşdır.
- Tətbiqi açanda bildiriş icazəsinə **İcazə ver** deyin.
- "Batareya məhdudiyyətini söndür" düyməsi ilə tətbiqi **Məhdudiyyətsiz** edin (Samsung arxa planda tətbiqləri yatırdır).
